# Проверки Stopscroll Android

Версия `30000071` прошла аппаратную проверку на Android 13, arm64-v8a,
пользователь 0, Wi-Fi IPv4. Это границы проверенного окружения, а не заявление
о поддержке всех телефонов и сетей.

## Результаты

| Проверка | Результат |
| --- | --- |
| Подписанная установка и импорт | Конфигурации сайтов совпадают; расход телефона не импортируется с desktop |
| Разрешённый HTTPS, исключение и закрытый YouTube | Проверены из отдельного UID; постороннее приложение не получает доступ к provider |
| TCP/UDP и раннее закрытие | Живые потоки закрываются, свежие попытки блокируются, остаток возвращается однократно |
| Повтор RPC | Повтор не резервирует время снова и не возвращает расход повторно |
| Минутный deadline | Нативное отсечение через 17 мс после deadline в активном режиме, 42 мс в forced Doze и 11 мс при выключенном Wi-Fi |
| Запрещённые уведомления | Сетевое закрытие работает без разрешения уведомлений |
| Chrome / HTTP/3 | Свежие GET/API проходят в открытом отрезке и не получают HTTP-ответов после закрытия и повторной попытки |
| Обновление и перезагрузка | Сохраняются политика, timezone и расход; новый boot списывает незавершённый резерв полностью |
| Экран и USB одновременно | Устаревшее действие получает CONFLICT; новый grant не возникает; закрытие с экрана работает |
| Отключение USB | X и YouTube заблокированы, обычный сайт загружается |
| Wi-Fi | Восстановление сети проверено |
| Независимость компонентов | Действующие правила desktop и Telegram сохранены |

Задержки — измерения конкретного устройства, не гарантии для других телефонов.
Сэмпл Doze получен после deadline без промежуточных ADB-команд, способных разбудить
телефон. Проверки Chrome проводились без очистки браузерных данных.

Для этой версии также выполнены 1 425 Android host-тестов и 276 Python-тестов.
Эти числа относятся к проверенной версии; актуальное число определяется текущим
запуском. Host-тесты не заменяют сетевую проверку установленного APK.

## Ограничения проверки

- Мобильные данные, роуминг и реальный IPv6 не проверены.
- Переход через 04:00 и DST покрыт host-тестами; часы телефона физически не переводились.
- Офлайн-кэш может оставаться видимым после закрытия сети.
- Самоотчёт `status` или успешный `doctor` не доказывает фильтрацию трафика другого UID.
- Скрывающие домен механизмы приложений и альтернативный DNS ограничивают доменную фильтрацию.

## Повторная проверка

Команды host-тестов, настройки VPN/Always-on/lockdown и порядок аппаратной
проверки приведены в [руководстве Android](../android/README.md).
Ручной runner — [device_acceptance.py](../android/tests/device_acceptance.py),
тестовое приложение с отдельным UID — [probe](../android/tests/probe/).

Сценарии `basic` и `tcp` прошли через публичный runner. Остальные аппаратные
сценарии измерены отдельным ручным стендом на том же подписанном APK. Отчёты
устройств, реальные политики, ключи и пароли хранятся вне Git.
