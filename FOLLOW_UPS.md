# Follow ups

## 1. Telegram на Android

- Собрать отдельный Android-клиент с запретом выбранных каналов по имени и ID.
- Переносить список запретов с компьютера по USB.
- Закрыть поиск, прямые ссылки, профили, истории и медиагалереи запрещённых каналов.
- Проверить переход с официального клиента, повторный вход и обновления APK.
- Сохранить доступ к разрешённым чатам; root для основной функции не требуется.

## 2. DNS-фильтр Android и USB-проверка

- Выбрать Android-фильтр и способ применения тех же правил, что на компьютере.
- При авторизованном USB/ADB-подключении проверять установку, версию, запуск,
  конфигурацию и реальную фильтрацию запрещённого/разрешённого адреса.
- Передавать список сайтов, режимы, лимиты и задержки; после отключения USB
  телефон должен самостоятельно использовать последнюю полученную конфигурацию.
- Предусмотреть команды управления и отчёт о сбоях без постоянной синхронизации.
- Учесть один VPN на профиль, автозапуск/энергосбережение и ограничения DNS.
- Для строгого закрытия сайтов предусмотреть браузерный уровень: DNS не
  блокирует кэш и все варианты повторного использования соединений.
- Отдельно решить, независимы ли бюджеты устройств: общий расход в реальном
  времени требует связи или заранее распределённых квот.

Эти два пункта отложены по запросу пользователя. Получение root и разблокировка
загрузчика не являются обязательными предварительными шагами.
